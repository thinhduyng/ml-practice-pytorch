# The Machine Learning Landscape

## The essence of Machine Learning

- A pattern exists
- We cannot pin it down mathematically
- We have data on

-> We can use Machine Learning

## Types

- Guiding method during training (supervised, unsupervised,...)
- Can learn incrementally on the fly or not (online vs batch learning)
- Work by comparing new data points to known data points, or detecting patterns (instance-based vs model-based learning)

## Main challenges

- Insufficient amount of data
- Nonrepresentative training data
- Poor-quality data
- Irrelevant features
- Overfitting/Underfitting
- Deployment

## Testing and Validating

> No Free Lunch (NFL) Theorem: no assumption about data -> no assumption about the model

- To test if it's the right model -> use test data
- NFL theorem -> not possible to evaluate all models => make reasonable amount of assumption
